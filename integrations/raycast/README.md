# Raycast

1. Run `chmod +x *.sh` in this directory.
2. In Raycast, choose **Extensions → Script Commands → Add Directories** and add this folder.
3. Run **New Quikanva Sketch** or **Open Quikanva Gallery**; assign hotkeys or aliases as needed.

Both commands run silently and invoke local `quikanva://new` or `quikanva://gallery` routes. A specific sketch opens with `quikanva://open?id=<UUID>`.
